# 라벨링 가이드 (v0.1)

작성: 2026-10-31 / 대상: `eval/golden.jsonl`

시술 등록 문구(제목·설명)에 한국·일본 의료광고 규제 위반 소지가 있는지 사람이 판정해 정답을 만든다. 이 정답으로 Phase 1(long-context baseline)과 Phase 2(RAG)의 성능을 잰다.

> 이 가이드는 법률 자문이 아니다. 경계가 애매한 판정은 `note`에 이유를 남기고, 법무 확인 결과가 나오면 갱신한다.

## 1. 판정 단위와 전제

- **판정 단위**: 시술 1건 = 제목(`title`) + 설명(`description`).
- **노출 대상**: 일본 거주자. 일본어 문구가 기본이고, 병원이 한국어로 입력한 문구도 있다.
- **적용 법**: 한국·일본 둘 다 본다. 운영 주체는 한국 자회사로 전제한다 (`docs/design.md` §2).
- **입력 언어와 무관하게 양국 기준을 모두 적용한다.** 한국어 문구도 번역돼 일본에 노출되고, 일본어 문구도 한국 법인이 게시한다.

## 2. 판정 등급 (`verdict`)

| 값 | 기준 |
| --- | --- |
| `violation` | 법령·가이드라인 본문이나 공식 사례에 거의 그대로 해당하는 표현이 하나 이상 있다 |
| `caution` | 해석 여지가 있거나, 법무 확인이 끝나지 않은 쟁점에 해당한다. 사람이 검토해야 한다 |
| `ok` | 위반·주의 표현이 없다 |

- 문서 전체 `verdict` = finding 중 가장 높은 등급 (`violation` > `caution` > `ok`).
- 한국·일본 중 한쪽만 걸려도 그 등급으로 둔다.
- **법무 확인 대기 쟁점은 `caution`으로 둔다.** 현재 대상: 일본 미승인 제품의 한국 내 시술(C4 일부), 한국 정부 지정·등록 표기의 일본 측 해석(C7 일부).
- **회사 결정 사항 (2026-10-31):**
  - 한국 의사를 "医師"로 표기하는 것은 허용한다. → C3는 판정하지 않는다.
  - 운영 주체는 한국 자회사로 확정이고, 외국인환자 유치사업자로 등록돼 있다. → 외국인환자 유치를 위한 통역·픽업 등 편의 제공은 그 자체로는 판정하지 않는다 (의료법 27조③2호 예외).

## 4. finding 작성 규칙

```json
{"span": "絶対安全", "field": "description", "category": "C1", "country": "JP",
 "severity": "violation",
 "rule": "医療法 第6条の5第1項 / 医療広告等ガイドライン 第3-1 1(1)",
 "source_file": "data/raw/jp/医療広告等ガイドライン_最終改正20260330.pdf",
 "reason": "...", "suggestion": "..."}
```

- **`span`**: 입력 문자열에 **글자 그대로** 있는 부분 문자열. 가장 짧게, 그러나 의미가 통하게 자른다 ("絶対安全な手術" → "絶対安全").
- **누락(C8)은 `span: null`**, `field: null`로 둔다.
- **같은 span이 양국에 걸리면 finding을 나라별로 따로 쓴다.** 검색 평가에서 나라별 근거를 따로 보기 때문이다.
- **`severity`**: finding 단위 등급. `violation` / `caution`.
- **`rule`**: 조문까지 쓴다. 법령이 있으면 법령 먼저, 그다음 가이드라인. 형식: `법령명 제X조제Y항제Z호 / 가이드라인 항목`.
- **`source_file`**: `data/raw/` 아래 실제 파일 경로. RAG 검색 재현율(recall) 평가에 쓴다.
- **`suggestion`**: 같은 의미를 살리되 위반이 아닌 문장. 원문 언어로 쓴다. 정보 추가가 필요하면 `[ ]`로 병원이 채울 자리를 표시한다 (예: `[標準的な費用]`).

## 5. 경계 사례 결정 규칙

| 표현 | 판정 | 이유 |
| --- | --- | --- |
| 自然な仕上がりを目指します / 자연스러운 결과를 목표로 | ok | 목표 표현이고 결과 보장이 아니다 |
| 自然な仕上がりになります / 티 안 나는 완벽한 결과 | violation C1 | 결과 보장 |
| 比較的安全 / 비교적 안전한 | violation C1 | ガイドライン 第3-1 1(3)에 그대로 있는 예 |
| ダウンタイムが少ない | caution C1 | 비교 대상이 불명확. 구체 기간을 쓰면 ok |
| ダウンタイムなし / 다운타임 없음 | violation C1·C8 | 허위·리스크 누락 |
| 満足度○% (조사 방법 명시) | caution C1 | 출처·조사 주체·기간·범위가 다 있으면 caution, 없으면 violation |
| 症例写真 + 치료 내용·비용·리스크 상세 설명 | caution C2 | JP는 상세 설명이 있으면 허용 여지, KR 의료해외진출법 15조는 전후 사진 금지 |
| 医療ハイフ, ヒアルロン酸 (일반명) | ok | 제품 특정이 안 된다 |
| 상품명 (ボトックスビスタ, ボツラックス 등) | violation C4 | ガイドライン 第3-1 1(8)イ① 商品名 금지 / KR 약사법 68조⑥ |
| 가격 범위 명시 ("165,000円〜330,000円") | ok | 限定解除 ③을 충족하는 방향 |
| 할인 전후 가격 병기, 기간 한정 | violation C5 | ガイドライン 第3-1 1(8)ア① |
| 韓国の○○専門医, 韓国人医師が担当 | ok | 회사 결정으로 허용 (C3 미사용) |
| 空港送迎・通訳無料 / 공항 픽업·통역 무료 | ok | 등록 유치사업자의 외국인환자 유치 행위. 단, 가격 할인과 묶어 강조하면 C5로 본다 |
| 티 안 나는 (단독) | caution C1 | 결과 보장처럼 읽힐 수 있다. "완벽한" 등과 붙으면 violation |
| し放題 / 回数無制限 | violation C1·C5 | 事例解説書(9). 毛周期 등으로 실제 횟수가 제한된다 |
| 最安値 / 9,800円〜 (최저가만) | violation C1·C8 | 최상급 표현 + 限定解除 ③ 비용 범위 누락 |
| 승인 효능 외 사용 (エラ 보톡스 등) | 고지하면 ok | 승인 범위 외라는 점과 救済制度 대상 외일 수 있다는 점을 쓰면 ok. 없으면 C4 violation (事例解説書(30)) |
| 法令·ガイドライン 遵守 강조 | violation C7 | 事例解説書(4). 당연한 의무를 특별한 것처럼 강조 |
| 할인 조건(금액·대상·기간) 명시 | KR ok / JP caution | KR 시행령 23조①13은 불명확할 때만 위반. JP는 費用強調 소지. 단, 할인 전후 가격을 병기하면 JP violation |
| 할인 조건 없는 특별가·전용가 | violation C5 (KR·JP) | KR 시행령 23조①13 불명확한 할인 / JP 費用強調 |
| 자유진료 시술 소개인데 비용·리스크가 없음 | violation C8 (KR·JP 각각) | JP 限定解除 ③④ 미충족 / KR 56조②7. 병원 소개·상담 안내·후기 캠페인처럼 특정 시술 소개가 아니면 제외. 비용만 있고 리스크가 없어도 해당 |
| 외국 정부의 인가·인증 사칭 (厚生労働省認可 등) | violation C7 (KR) | KR 56조②3 거짓·②14 인증. ②14 나목 예외는 한국 정부 기관만 해당 |
| 명의 / 名医 | violation (KR C7 ②9, JP C1 1(2)) | KR은 법적 근거 없는 명칭, JP는 최상급 표현 |
| 기간이 불명확한 할인 (今だけ, 期間限定, 선착순) | violation C5 (KR·JP) | KR 시행령 23조①13 불명확한 할인 조건 / JP 費用強調 |
| 한국 법령에만 있는 금지 (수술 장면 ②6, 비의료인 진단 27조①) | KR만 | JP 의료광고 규정에 직접 대응하는 조항이 없다 |
| 의료기기 상품명 (리쥬란 등) | JP만 C4 | KR 약사법 68조⑥은 전문의약품 대상. 의료기기법은 아직 자료에 없음 |
| 最適な施術 / 최적의 시술 | violation C1 | 事例解説書(9) 事例① |
| 국제 인증(JCI 등) 표기 | KR caution C7 | 인증 기간을 함께 써야 한다 (복지부 가이드라인) |

## 6. 메타 필드

- `label_status`: `draft`(초안) → `reviewed`(2인 검토) → `final`.
- `split`: `dev` / `test`. test는 튜닝하는 동안 보지 않는다. 시드는 모두 `dev`.
- `origin`: 샘플 출처. `synthetic`(가이드라인 예시를 바탕으로 새로 작성), `case_book`(事例解説書 등 사례에서 각색), `real`(실제 등록 데이터, 개인정보·병원명 마스킹).
- `note`: 판정 근거나 애매한 점.

## 7. 목표 분포 (100건 기준)

- `violation` 50%, `caution` 20%, `ok` 30%
- C1·C2·C4~C9 카테고리마다 최소 5건
- 언어: 일본어 70%, 한국어 30%
- 현재 50건: violation 30 / caution 5 / ok 15, 일본어 35 / 한국어 15. **C9 샘플이 3건, caution이 5건으로 아직 부족하다.**

## 8. 검토 절차

1. 라벨러 A가 작성한다 (`draft`).
2. 라벨러 B가 독립적으로 판정하고 차이를 맞춘다 (`reviewed`).
3. 차이가 컸던 경계 사례는 §5 표에 규칙으로 추가한다.
4. 법무 확인이 끝나면 `caution` 대기 항목을 다시 판정한다 (`final`).
