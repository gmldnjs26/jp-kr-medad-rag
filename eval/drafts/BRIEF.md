# 신규 평가 샘플 작성 브리프 (2026-11-07)

프로젝트: `/Users/heewongwak/Documents/jp-kr-medad-rag` — 한국 미용 클리닉이 일본 거주자 대상 플랫폼에 등록하는 시술 광고(제목+설명)를 한·일 의료광고 규제로 검수하는 RAG. 검색 대상 자료를 새로 정했으므로, 새 자료를 근거로 한 평가 샘플을 추가한다.

## 반드시 먼저 읽을 것
- `docs/policy.md` — 판정 기준. 등급(violation/caution/ok), 카테고리 C1~C9, finding 작성 규칙(§4: 같은 표현이 양국에 걸리면 나라별로 finding을 따로), 경계 사례(§5), C8(필수 정보 누락) 규칙.
- `eval/golden.jsonl` 앞쪽 몇 줄 — 기존 샘플 형식과 문체. 이 파일은 수정하지 않는다.

## 할 일
담당 문서를 처음부터 끝까지 읽고, 그 문서가 다루는 위반 유형·판단 기준마다 평가 샘플을 만든다. 건수는 문서 내용에 맞게 정한다(상한 없음). 미용 시술 광고와 관계없는 부분(예: 일반 의약품 유통, 병원 행정)은 건너뛴다.
- verdict 비율 목표: violation 약 60%, caution 약 20%, ok 약 20%. ok 샘플은 그 문서의 기준을 지킨 광고(경계선 근처)로 만든다.
- 언어: 한국 문서는 ko와 ja를 반반, 일본 문서는 ja 위주. 플랫폼은 일본 거주자에게 보여 준다.
- 시술은 다양하게 (쌍꺼풀, 코, 지방흡입, 보톡스, 필러, 리프팅, 레이저, 피부, 탈모, 치아 미백 등).

## 금지 (평가 누수 방지)
- 문서에 실린 예시 문장을 그대로 또는 거의 그대로 쓰지 않는다. 같은 위반을 다른 말, 다른 시술로 새로 쓴다. 문서 예시가 「부작용 없는 안전한 시술」이면 「붓기 걱정 제로, 다음 날 바로 출근」처럼 바꾼다.
- 기존 golden.jsonl 샘플과 거의 같은 문구도 쓰지 않는다.

## 출력: JSONL 한 줄 = 샘플 하나 (담당 파일에만 쓴다. 다른 파일은 수정하지 않는다)
```json
{"id": "<그룹문자><2자리 번호, 예: A01>", "split": "dev", "lang": "ko|ja",
 "title": "...", "description": "...", "verdict": "violation|caution|ok",
 "findings": [ ... ], "label_status": "draft", "origin": "synthetic",
 "note": "2026-11-07 신규 자료 기반: <주 근거 문서 doc 이름> p.<페이지>"}
```
finding 형식은 golden.jsonl과 같고 `evidence`를 추가한다.
```json
{"span": "문구 그대로 또는 null(C8만)", "field": "title|description|null", "category": "C1~C9",
 "country": "JP|KR", "severity": "violation|caution",
 "rule": "법적 근거 조문. 예: 의료법 제56조제2항제8호 / 医療法 第6条の5第2項第2号 / 医療広告等ガイドライン 第3-1 1(3)",
 "source_file": "data/raw/... (실제로 있는 파일 경로)",
 "reason": "...", "suggestion": "원문 언어로 쓴 수정안, 병원이 채울 곳은 [ ]",
 "evidence": [ ... ]}
```
`evidence` = 이 finding의 근거가 실린 **검색 대상 자료 안의 위치**. 아래 두 형식 중 하나.
- PDF 페이지형: `{"doc": "<doc 이름>", "page": <정수>, "quote": "<그 페이지 본문에 글자 그대로 있는 15~60자>"}`
- 조문형: `{"doc": "<doc 이름>", "ref": "<조문 ref>"}`

페이지 번호 규칙 (중요):
- `page`는 인쇄된 쪽 번호가 아니라 **pypdf로 읽은 1부터 시작하는 순번**이다.
- 아래처럼 읽어서 확인하고, `quote`가 그 페이지 텍스트(공백을 하나로 줄인 것)에 글자 그대로 들어 있는지 스크립트로 검증한다.
```bash
cd /Users/heewongwak/Documents/jp-kr-medad-rag
.venv/bin/python -I -c "
import re,sys; from pypdf import PdfReader
r=PdfReader('data/raw/kr/<파일>'); t=r.pages[<page>-1].extract_text() or ''
print(re.sub(r'[ \t　]+',' ',t))"
```

evidence 작성 기준:
- 주 근거 문서(담당 문서)의 해당 페이지는 반드시 넣는다.
- 같은 위반의 다른 나라 finding(§4)도 쓴다. 그 finding의 evidence는 위 표의 자료에서 찾을 수 있으면 넣고(예: KR 과장 → `의료법 제56조제2항제8호`, JP 과장 → `医療広告等ガイドライン 第3-1 1(3)`), 없으면 빈 리스트로 둔다.
- 한 finding에 근거가 여러 곳이면 모두 넣는다.
